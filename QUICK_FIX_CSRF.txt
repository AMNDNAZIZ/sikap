═══════════════════════════════════════════════════════════════
  APA ITU CSRF?
═══════════════════════════════════════════════════════════════

CSRF = Cross-Site Request Forgery

Serangan dimana attacker membuat user melakukan action yang tidak
diinginkan di website yang sudah ter-authenticate.

CSRF Token = Random string yang di-generate server untuk validasi
bahwa request berasal dari form yang legitimate.

Cara Kerja:
1. Server generate token saat render form
2. Token di-embed di form sebagai hidden field
3. Saat submit, server validate token
4. Jika valid → Request diterima
5. Jika invalid → Request ditolak (error "action not allowed")

═══════════════════════════════════════════════════════════════
  CARA MENAMBAHKAN CSRF TOKEN
═══════════════════════════════════════════════════════════════

Method 1: csrf_field() Helper (RECOMMENDED)
────────────────────────────────────────────────────────────
<form method="post">
    <?= csrf_field() ?>
    <!-- form fields -->
</form>

Method 2: Manual Hidden Input
────────────────────────────────────────────────────────────
<form method="post">
    <input type="hidden" name="<?= csrf_token() ?>" 
           value="<?= csrf_hash() ?>">
    <!-- form fields -->
</form>

Method 3: AJAX Request
────────────────────────────────────────────────────────────
fetch('/api/endpoint', {
    method: 'POST',
    headers: {
        'X-CSRF-TOKEN': '<?= csrf_hash() ?>'
    },
    body: JSON.stringify(data)
});

═══════════════════════════════════════════════════════════════
  COMMON ISSUES
═══════════════════════════════════════════════════════════════

Issue: Token Expired
→ Refresh halaman untuk generate token baru
→ Default expiry: 2 hours

Issue: Multi-Tab Error
→ Set tokenRandomize = false di app/Config/Security.php

Issue: AJAX Request Gagal
→ Include token di header: X-CSRF-TOKEN

Issue: Form di-cache
→ Disable cache untuk form pages

═══════════════════════════════════════════════════════════════
  DEBUGGING
═══════════════════════════════════════════════════════════════

1. Check token di form (view source):
   <input type="hidden" name="csrf_test_name" value="...">

2. Check token di session (add di controller):
   log_message('debug', 'CSRF: ' . session()->get('csrf_test_name'));

3. Check CSRF config:
   app/Config/Security.php

4. Disable CSRF (TESTING ONLY!):
   app/Config/Filters.php → comment out 'csrf'
   ⚠️ JANGAN disable di production!
