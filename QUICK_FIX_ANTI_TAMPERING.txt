   "File sistem telah dimodifikasi"
   "LICENSE ERROR: CRITICAL_FILE_MODIFIED"

┌──────────────────────────────────────────────────────────────────────────────┐
│ PENYEBAB                                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

🔍 Hash file berubah setelah update (NORMAL!)
🔍 Sistem keamanan mendeteksi perubahan
🔍 Hash perlu di-regenerate

┌──────────────────────────────────────────────────────────────────────────────┐
│ SOLUSI CEPAT (2 MENIT)                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

1️⃣ UPLOAD SCRIPT
   📁 Upload: regenerate_hash_after_update.php
   📍 Ke root folder (sejajar dengan index.php)

2️⃣ AKSES SCRIPT
   🌐 http://yourdomain.com/regenerate_hash_after_update.php
   
   Jika tidak bisa akses (remote):
   🌐 http://yourdomain.com/regenerate_hash_after_update.php?key=update2026

3️⃣ KLIK TOMBOL
   ▶️ Klik: "Regenerate All Hashes"
   ⏱️ Tunggu proses selesai (beberapa detik)

4️⃣ VERIFY
   ✅ Muncul: "Berhasil!"
   ✅ Akses aplikasi normal
   ✅ Error anti-tampering hilang

5️⃣ HAPUS SCRIPT (KEAMANAN!)
   🗑️ Hapus: regenerate_hash_after_update.php
   🔒 Jangan biarkan script ini di server

┌──────────────────────────────────────────────────────────────────────────────┐
│ ALTERNATIF: MANUAL DELETE HASH                                               │
└──────────────────────────────────────────────────────────────────────────────┘

Jika tidak bisa akses script:

1️⃣ Via FTP/cPanel File Manager:
   🗑️ Hapus: app/Config/.security_hash
   🗑️ Hapus: app/Config/.lic_hash

2️⃣ Akses Aplikasi:
   🌐 http://yourdomain.com/
   ✅ Sistem auto-generate hash baru

└──────────────────────────────────────────────────────────────────────────────┘

✅ License Hash (.lic_hash)

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

❓ Error: "Could not save security hashes"
   → Check write permissions: chmod 755 app/Config/

❓ Error: "Access denied"
   → Akses dengan key: ?key=update2026
   → Atau akses dari localhost

❓ Sudah regenerate tapi masih error
   → Clear cache browser (Ctrl+Shift+Delete)
   → Check log: writable/logs/
   → Coba delete hash files manual
