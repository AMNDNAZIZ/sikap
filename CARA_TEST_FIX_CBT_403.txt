TROUBLESHOOTING:

MASALAH: Masih error 403
SOLUSI:
□ Clear browser cache dan cookies
□ Logout dan login ulang
□ Check CSRF expires di app/Config/Security.php (harus >= 21600)
□ Check server logs untuk detail error

MASALAH: Token tidak refresh
SOLUSI:
□ Check endpoint refreshCsrf exists di controller
□ Check console untuk error JavaScript
□ Verify window.csrfToken dan window.csrfHash ada

MASALAH: Infinite retry loop
SOLUSI:
□ Check retry mechanism (hanya 1x retry)
□ Check refreshCsrf endpoint return token/hash
□ Clear browser cache
