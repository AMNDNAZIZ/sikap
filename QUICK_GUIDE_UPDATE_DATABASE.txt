┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

❓ Error: "Table doesn't exist"
   → Check apakah tabel parent ada (announcements, students, subjects)
   → Restore dari backup jika perlu

❓ Error: "Duplicate column name"
   → Ignore (kolom sudah ada = OK)
   → Lanjutkan ke query berikutnya

❓ Error: "Cannot add foreign key constraint"
   → Check data yang tidak konsisten
   → Hapus atau perbaiki data tersebut

❓ Error: "Access denied"
   → Login sebagai root atau user dengan privilege penuh
