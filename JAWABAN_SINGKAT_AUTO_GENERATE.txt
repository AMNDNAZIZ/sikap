🔄 WORKFLOW INSTALASI BARU:

Step 1: Pembeli Copy File ke Server Baru
   └─ File .lic_hash tidak ada
   └─ File .security_hash tidak ada

Step 2: Pembeli Akses Aplikasi Pertama Kali
   └─ checkIntegrity() detect file tidak ada
   └─ ✅ AUTO-GENERATE .lic_hash
   └─ ✅ AUTO-GENERATE .security_hash
   └─ Redirect ke /activate

Step 3: Pembeli Input Kode Lisensi
   └─ Input license_key dari pengembang
   └─ POST ke server lisensi online
   └─ Server validasi dan approve

Step 4: Aplikasi Simpan Lisensi
   └─ Simpan ke database
   └─ ✅ AUTO-BIND machine_id
   └─ ✅ AUTO-BIND hardware_signature
   └─ Status: active

Step 5: Aplikasi Aktif
   └─ ✅ BISA DIGUNAKAN

═══════════════════════════════════════════════════════════════════════════════

🔄 WORKFLOW PERPANJANGAN:

Step 1: Lisensi Expired
   └─ User akses aplikasi
   └─ System detect expired

Step 2: Auto-Renewal (Otomatis)
   └─ attemptAutoRenewal() dipanggil
   └─ POST ke server: action=renew
   └─ Server response: new expiry

Step 3a: Jika Berhasil
   └─ Update database lokal
   └─ ✅ APLIKASI LANJUT (tidak redirect)

Step 3b: Jika Gagal
   └─ Redirect ke /activate
   └─ User klik "Cek Pembaruan"
   └─ Manual sync dari server
   └─ ✅ APLIKASI AKTIF KEMBALI
