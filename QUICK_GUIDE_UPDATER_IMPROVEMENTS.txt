⚠️ TROUBLESHOOTING:

MASALAH: Migrasi gagal setelah update
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
GEJALA:
• File ter-update
• Tapi ada warning: "Migrasi gagal: ..."
• Aplikasi mungkin error

SOLUSI:
1. Check log: writable/logs/log-YYYY-MM-DD.php
2. Lihat error message migrasi
3. Fix migrasi manual (edit file migrasi)
4. Klik "Jalankan Migrasi" manual
5. ✅ Selesai

CATATAN:
• File tetap ter-update (tidak rollback)
• Hanya migrasi yang gagal
• Bisa di-fix manual

---

MASALAH: File index.php tidak ter-update (root installation)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
GEJALA:
• Update tampilan tidak muncul
• index.php masih versi lama

SOLUSI:
1. Check: Apakah zip berisi index.php?
   • Extract zip di komputer
   • Lihat isi: harus ada index.php di root
2. Jika tidak ada:
   • Generate ulang patch di localhost
   • Pastikan index.php ada di ROOTPATH
3. Upload ulang zip baru
4. ✅ Selesai

---

MASALAH: Backup tidak ter-create
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
GEJALA:
• Update berhasil
• Tapi tidak ada folder backup

SOLUSI:
1. Check permission: writable/backups/
   • chmod 755 writable/backups/
2. Check disk space
   • df -h
3. Check log untuk error message
4. Backup manual sebelum update berikutnya
