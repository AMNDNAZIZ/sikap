   5. Maintenance mode OFF → User lain bisa akses
   6. ✅ Aplikasi normal (tidak ada error!)

✅ Maintenance Mode Otomatis
   - User lain diblokir saat update
   - Admin yang update tetap bisa akses
   - Halaman maintenance cantik dengan auto-refresh

✅ Auto-Migrate Database
   - Database otomatis ter-update setelah extract file
   - Tidak ada gap waktu aplikasi broken

✅ Include File Root
   - File index.php, .htaccess ter-include dalam zip
   - Support kedua struktur instalasi (standard & root)

✅ Backup Otomatis
   - Critical files di-backup sebelum update
   - Rollback otomatis jika gagal

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

❓ Maintenance mode tidak OFF setelah update?
   → Hapus manual: writable/.maintenance

❓ Migrasi gagal?
   → Fix migrasi manual
   → Klik "Jalankan Migrasi"

❓ File tidak ter-update?
   → Check log: writable/logs/
   → Check permission folder

❓ User masih melihat maintenance page?
   → Tunggu 5 detik (auto-refresh)
   → Atau manual refresh (F5)
