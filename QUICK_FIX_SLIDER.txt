  QUICK FIX: SLIDER UPLOAD GAGAL
═══════════════════════════════════════════════════════════════

MASALAH:
Upload slider di http://localhost/siakad/admin/cms/sliders gagal

SOLUSI CEPAT:
═══════════════════════════════════════════════════════════════

1. REGENERATE HASH (jika ada error anti-tampering)
   ────────────────────────────────────────────────────────────
   php regenerate_hash_after_update.php
   
   Atau via browser:
   http://localhost/siakad/regenerate_hash_after_update.php

2. RUN DIAGNOSTIC
   ────────────────────────────────────────────────────────────
   http://localhost/siakad/diagnostic_slider.php
   
   Script ini akan check:
   ✓ PHP configuration
   ✓ Upload settings
   ✓ Upload folder
   ✓ Database & table
   ✓ Controller & views

3. FIX COMMON ISSUES
   ────────────────────────────────────────────────────────────
   
   Issue: "uploaded[image]"
   → Form harus punya enctype="multipart/form-data"
   → Field name harus "image"
   
   Issue: "max_size"
   → File terlalu besar (> 2MB)
   → Kompres gambar atau edit php.ini
   
   Issue: "is_image"
   → File bukan gambar
   → Upload JPG/PNG/WEBP only
   
   Issue: "Gagal memindahkan file"
   → Folder tidak writable
   → chmod 755 uploads/sliders
   
   Issue: "Table not found"
   → php spark migrate

4. TEST UPLOAD
   ────────────────────────────────────────────────────────────
   http://localhost/siakad/admin/cms/sliders/create
   
   Test dengan:
   ✓ Gambar valid (JPG/PNG < 2MB)
   ✓ Gambar > 2MB (should fail)
   ✓ File non-image (should fail)
   ✓ Tanpa upload (should fail)

5. CHECK LOG (jika masih error)
   ────────────────────────────────────────────────────────────
   writable/logs/log-2026-02-25.log
   
   Cari keyword: slider, upload, error, Failed
