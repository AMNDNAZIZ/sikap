═══════════════════════════════════════════════════════════════
  JAWABAN: Error "Action Not Allowed"
═══════════════════════════════════════════════════════════════

MASALAH:
Setelah dicoba ulang muncul error:
"Error! The action you requested is not allowed."

PENYEBAB:
Form tidak memiliki CSRF token (Cross-Site Request Forgery protection)

CSRF token adalah security feature di CodeIgniter 4 untuk mencegah
serangan CSRF. Semua form POST harus memiliki token ini.

═══════════════════════════════════════════════════════════════
  SOLUSI - SUDAH DIPERBAIKI! ✅
═══════════════════════════════════════════════════════════════

File: app/Views/admin/cms/sliders/form.php

Tambahan:
<?= csrf_field() ?>

Ini akan generate hidden input:
<input type="hidden" name="csrf_test_name" value="random_token">

  CARA TEST ULANG
═══════════════════════════════════════════════════════════════

1. REFRESH halaman form (PENTING!)
   http://localhost/siakad/admin/cms/sliders/create

2. Upload gambar dan isi form

3. Klik "Simpan Slider"

4. Seharusnya berhasil tanpa error!

═══════════════════════════════════════════════════════════════
  PENJELASAN CSRF
═══════════════════════════════════════════════════════════════

CSRF = Cross-Site Request Forgery

Contoh serangan:
1. User login ke bank.com
2. User buka website jahat evil.com
3. evil.com punya form tersembunyi yang submit ke bank.com
4. Transfer uang terjadi tanpa sepengetahuan user

CSRF Token mencegah ini dengan:
1. Server generate random token saat render form
2. Token di-embed di form
3. Saat submit, server validate token
4. Jika token tidak valid → Request ditolak

Ini kenapa form harus punya <?= csrf_field() ?>

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Jika masih error "action not allowed":

1. Hard refresh halaman (Ctrl+F5)
   → Generate token baru

2. Check view source, cari:
   <input type="hidden" name="csrf_test_name" value="...">
   → Pastikan ada

3. Clear browser cache dan cookies
   → Hapus session lama

4. Check session:
   writable/session/
   → Pastikan folder writable

5. Check CSRF config:
   app/Config/Security.php
   → Pastikan csrfProtection = 'session'
