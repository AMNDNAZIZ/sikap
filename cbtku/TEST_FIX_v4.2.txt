│ 🐛 BUG YANG DITEMUKAN                                                    │
└───────────────────────────────────────────────────────────────────────────┘

  PHP Reference Corruption Bug!
  
  Masalah: Loop pertama menggunakan reference (&$s), tapi tidak di-unset
           setelah loop selesai. Loop kedua tanpa reference menyebabkan
           elemen terakhir array di-overwrite dengan elemen sebelumnya.
  
  Hasil: Dewi Puspita (row 4) muncul 2x, Eman Ruhiman (row 5) hilang

┌───────────────────────────────────────────────────────────────────────────┐
│ 🔧 FIX YANG DITERAPKAN                                                   │
└───────────────────────────────────────────────────────────────────────────┘

  Menambahkan 1 baris code: unset($s);
  
  Lokasi: app/Controllers/Admin/CbtAktivitas.php (setelah line 276)
  
  Sebelum:
  ┌─────────────────────────────────────────┐
  │ foreach ($sessions as &$s) {            │
  │     // modify $s                        │
  │ }                                       │
  │ // ❌ $s masih reference!               │
  │ foreach ($sessions as $s) {             │
  │     // corrupt array!                   │
  │ }                                       │
  └─────────────────────────────────────────┘
  
  Sesudah:
  ┌─────────────────────────────────────────┐
  │ foreach ($sessions as &$s) {            │
  │     // modify $s                        │
  │ }                                       │
  │ unset($s); // ✅ Break reference!       │
  │ foreach ($sessions as $s) {             │
  │     // safe now!                        │
  │ }                                       │
  └─────────────────────────────────────────┘
