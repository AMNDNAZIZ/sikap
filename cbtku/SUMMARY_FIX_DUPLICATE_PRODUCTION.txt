❌ Siswa muncul duplicate di aktivitas detail
❌ Siswa terakhir tidak muncul
❌ Contoh: Dewi Puspita muncul 2x, Eman Ruhiman hilang

═══════════════════════════════════════════════════════════════════
  ROOT CAUSE
═══════════════════════════════════════════════════════════════════

PHP Reference Corruption Bug

Loop pertama: foreach ($sessions as &$s)  ← reference
Loop kedua: foreach ($sessions as $s)     ← no reference
Result: Elemen terakhir array corrupt!

═══════════════════════════════════════════════════════════════════
  SOLUSI
═══════════════════════════════════════════════════════════════════

Tambah 1 baris code: unset($s);

File: app/Controllers/Admin/CbtAktivitas.php
Line: ~277 (setelah foreach dengan reference)

BEFORE:
  foreach ($sessions as &$s) {
      // modify
  }
  foreach ($sessions as $s) {  ← BUG!
      // count
  }

AFTER:
  foreach ($sessions as &$s) {
      // modify
  }
  unset($s);  ← FIX!
  foreach ($sessions as $s) {
      // count
  }
