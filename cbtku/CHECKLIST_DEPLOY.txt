TROUBLESHOOTING

  → Check database sudah dibuat

404 Not Found:
  → Check .htaccess ada
  → Check mod_rewrite enabled

  → Verify kredensial di config.php
  → Check user punya akses ke database

  → chmod 755 writable/updates/
