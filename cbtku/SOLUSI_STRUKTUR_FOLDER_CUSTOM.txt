SOLUSI: STRUKTUR FOLDER CUSTOM
===============================

🔴 MASALAH:
Script di: /home/cbtsmpi/public_html
Tapi tidak bisa find app/ dan writable/

Struktur folder Anda TIDAK STANDARD!

═══════════════════════════════════════════════════════════

🎯 ROOT CAUSE:

Struktur Standard CodeIgniter:
/home/user/
  ├── app/
  ├── public/
  │   └── index.php  ← Web root
  ├── writable/
  └── system/

Struktur Anda (kemungkinan):
/home/cbtsmpi/
  ├── public_html/  ← Web root (script ada di sini)
  ├── app/          ← Aplikasi di parent folder?
  ├── writable/
  └── system/

Atau:
/home/cbtsmpi/public_html/
  ├── app/          ← Semua di public_html?
  ├── writable/
  ├── system/
  └── index.php

═══════════════════════════════════════════════════════════

✅ SOLUSI:

1. DELETE fix_paths_diagnostic.php (tidak cocok)

2. UPLOAD fix_custom_structure.php
   - Upload ke public_html/
   - Script ini akan auto-detect struktur custom

3. AKSES:
   https://yourdomain.com/fix_custom_structure.php

4. LIHAT HASIL:
   Section 2: Detecting Application Root
   - Akan coba berbagai kemungkinan path
   - Menunjukkan path yang VALID (✅)
   
   Section 6: Error Log Analysis
   - Ini yang PENTING!
   - Lihat error CRITICAL atau ERROR
   - Ini penyebab sebenarnya blank page

🔧 SETELAH DETECT PATH:

Script akan check:
✅ Critical files (Database.php, LicenseFilter.php, dll)
✅ Writable folders (cache, logs, session)
✅ Error log (PENTING!)
✅ Database connection

Lihat Section 6: Error Log Analysis
→ Ini yang menunjukkan masalah sebenarnya!

═══════════════════════════════════════════════════════════

💡 COMMON ERRORS DI LOG:

ERROR: Database connection failed
→ Check .env file
→ Verify hostname, username, password, database

ERROR: Class 'LicenseProtector' not found
→ File ada tapi autoload issue
→ Check namespace atau re-upload

ERROR: License hash mismatch
→ Upload .lic_hash dan .lic_checksum dari localhost

ERROR: Permission denied
→ chmod 755 writable/
→ chmod 644 .lic_hash
