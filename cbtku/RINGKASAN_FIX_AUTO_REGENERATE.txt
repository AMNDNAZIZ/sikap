═══════════════════════════════════════════════════════════════
  BUG YANG DITEMUKAN
═══════════════════════════════════════════════════════════════

MASALAH:
--------
Auto-regenerate hash tidak bekerja karena format hash yang 
di-generate tidak match dengan format yang di-check oleh 
LicenseGuard.

LOKASI BUG:
-----------
1. app/Controllers/Activate.php (line 274-291)
2. app/Controllers/Admin/License.php (line 119-136)

DETAIL BUG:
-----------
❌ SALAH (Bug code):
   - Key: basename only (e.g., "LicenseFilter.php")
   - Value: SHA256 hash
   - Format: { "LicenseFilter.php": "sha256_abc..." }

✅ BENAR (Expected by LicenseGuard):
   - Key: Path relatif (e.g., "Filters/LicenseFilter.php")
   - Value: SHA1 hash
   - Format: { "Filters/LicenseFilter.php": "sha1_abc..." }

DAMPAK:
-------
1. File protected berubah → Hash mismatch detected ✅
2. Redirect ke /activate ✅
3. User klik "Periksa Pembaruan" ✅
4. Sistem regenerate hash TAPI FORMAT SALAH ❌
5. Hash tetap mismatch ❌
6. Loop terus menerus! 🔄

═══════════════════════════════════════════════════════════════
  FIX YANG DITERAPKAN
═══════════════════════════════════════════════════════════════

FILE YANG DI-FIX:
-----------------
✅ app/Controllers/Activate.php
✅ app/Controllers/Admin/License.php

PERUBAHAN:
----------
BEFORE (Bug):
-------------
$filesToHash = [
    APPPATH . 'Libraries/LicenseGuard.php',
    APPPATH . 'Filters/LicenseFilter.php',
    // ...
];

$hashes = [];
foreach ($filesToHash as $file) {
    if (file_exists($file)) {
        $hashes[basename($file)] = hash_file('sha256', $file);
        // ❌ basename() + SHA256
    }
}

AFTER (Fixed):
--------------
$protectedFiles = [
    'Filters/LicenseFilter.php',
    'Models/LicenseModel.php',
    // ...
];

$hashes = [];
foreach ($protectedFiles as $file) {
    $fullPath = APPPATH . $file;
    if (file_exists($fullPath)) {
        $hashes[$file] = sha1_file($fullPath);
        // ✅ Path relatif + SHA1
    }
}

HASIL:
------
✅ Format hash sekarang match dengan LicenseGuard
✅ Auto-regenerate sekarang bekerja dengan benar
✅ Tidak akan loop lagi setelah "Periksa Pembaruan"
