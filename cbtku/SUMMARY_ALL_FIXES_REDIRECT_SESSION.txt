═══════════════════════════════════════════════════════════════
  FIX #1: REDIRECT SETELAH SELESAI UJIAN
═══════════════════════════════════════════════════════════════

MASALAH:
  - Siswa langsung ke dashboard setelah selesai ujian
  - Seharusnya ke halaman hasil/selesai dulu

ROOT CAUSE:
  Bug di determineSubmitRedirect():
  - show_score='ya' → redirect ke 'selesai' (salah, harus 'hasil')
  - show_score='tidak' → redirect ke dashboard (salah, harus 'selesai')

SOLUSI:
  File: app/Controllers/Siswa/Cbt.php
  Method: determineSubmitRedirect() (line 877-893)
  
  BEFORE:
    if (show_score == 'ya') return selesai;
    return dashboard;  // ❌ SALAH
  
  AFTER:
    if (show_score == 'ya') return hasil;   // ✅ BENAR
    return selesai;                          // ✅ BENAR

EXPECTED FLOW:
  show_score='ya':    Selesai → Hasil (dengan nilai) → Dashboard
  show_score='tidak': Selesai → Selesai (tanpa nilai) → Dashboard

STATUS: ✅ FIXED

═══════════════════════════════════════════════════════════════
  FIX #2: SECURITY CHECK TERLALU KETAT DI HALAMAN HASIL
═══════════════════════════════════════════════════════════════

MASALAH:
  - Siswa tidak bisa lihat hasil jika selesai sebelum end_time
  - Contoh: Ujian 08:00-10:00, siswa selesai 09:30 → ditolak

ROOT CAUSE:
  Security check di hasil() memeriksa isPastEndTime:
  - Harus tunggu end_time untuk lihat hasil
  - Padahal seharusnya bisa langsung setelah selesai

SOLUSI:
  File: app/Controllers/Siswa/Cbt.php
  Method: hasil() (line 972-985)
  
  BEFORE:
    if (!isPastEndTime) return error;  // ❌ TERLALU KETAT
  
  AFTER:
    if (status != 'finished') return error;  // ✅ BENAR

EXPECTED BEHAVIOR:
  - Siswa bisa langsung lihat hasil setelah selesai
  - Tidak perlu tunggu end_time
  - Security: Hanya siswa dengan status='finished' yang bisa akses

STATUS: ✅ FIXED

═══════════════════════════════════════════════════════════════
  FIX #3: ERROR 400 "DATA TIDAK LENGKAP" SAAT SAVE JAWABAN
═══════════════════════════════════════════════════════════════

MASALAH:
  - Error console: POST saveAnswer 400 (Bad Request)
  - Server Error: Data tidak lengkap

ROOT CAUSE:
  Inkonsistensi cara mendapatkan studentId:
  - saveAnswer() tidak cek session('student_id') dulu
  - Jika session('student_id') ada tapi $user kosong → error

SOLUSI:
  File: app/Controllers/Siswa/Cbt.php
  Method: saveAnswer() (line 624-638)
  Method: selesai() (line 1378-1386)
  
  BEFORE:
    $studentId = $user['student_id'] ?? $user['related_id'] ?? null;
  
  AFTER:
    $studentId = $this->getStudentId();
  
  getStudentId() mengecek 3 fallback:
  1. session('student_id')
  2. $user['student_id']
  3. $user['related_id']

EXPECTED BEHAVIOR:
  - Jawaban tersimpan tanpa error
  - Lebih robust terhadap session corruption

STATUS: ✅ FIXED
