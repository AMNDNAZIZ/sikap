═══════════════════════════════════════════════════════════════
  STEP 1: CLEAR PHP OPCACHE
═══════════════════════════════════════════════════════════════

Pilih salah satu:

A. Via Browser (RECOMMENDED):
   1. Buka: http://localhost:8080/cbtku/clear_opcache.php
   2. Lihat pesan "✅ OPcache cleared successfully!"
   3. Lanjut ke Step 2

B. Via XAMPP Control Panel:
   1. Buka XAMPP Control Panel
   2. Klik "Stop" pada Apache
   3. Tunggu 2 detik
   4. Klik "Start" pada Apache
   5. Lanjut ke Step 2

C. Via Command (perlu Admin):
   1. Buka PowerShell as Administrator
   2. Run: net stop Apache2.4
   3. Run: net start Apache2.4
   4. Lanjut ke Step 2

═══════════════════════════════════════════════════════════════
  STEP 2: CLEAR BROWSER CACHE
═══════════════════════════════════════════════════════════════

Pilih salah satu:

A. Hard Refresh (QUICK):
   1. Buka halaman ujian
   2. Tekan: Ctrl + Shift + R
   3. Lanjut ke Step 3

B. Clear Cache (THOROUGH):
   1. Tekan: Ctrl + Shift + Del
   2. Pilih: "Cached images and files"
   3. Time range: "All time"
   4. Klik: "Clear data"
   5. Lanjut ke Step 3

C. Incognito Mode (EASIEST):
   1. Tekan: Ctrl + Shift + N
   2. Login sebagai siswa
   3. Lanjut ke Step 3

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

JIKA MASIH REDIRECT KE DASHBOARD:

1. Check Response JSON di Network tab:
   - Jika response: {"redirect": ".../siswa/cbt"}
     → OPcache belum clear, ulangi Step 1
   
   - Jika response: {"redirect": ".../siswa/cbt/hasil/..."}
     → Browser cache belum clear, ulangi Step 2
   
   - Jika tidak ada response atau error
     → Check Console tab untuk error

2. Check Console Log:
   - Jika tidak ada log [determineSubmitRedirect]
     → Method tidak dipanggil, ada error sebelumnya
   
   - Jika log menunjukkan URL salah
     → File belum ter-update (impossible, sudah verified)

3. Check File Timestamp:
   - Buka: app/Controllers/Siswa/Cbt.php
   - Lihat "Date modified"
   - Harus hari ini dengan waktu terbaru

4. Check Logs:
   - Buka: writable/logs/log-[date].php
   - Cari: [determineSubmitRedirect]
   - Lihat URL yang di-log
