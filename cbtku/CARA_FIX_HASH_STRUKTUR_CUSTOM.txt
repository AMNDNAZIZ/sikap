Q: Script tidak bisa menemukan folder cbtku?
A: 1. Pastikan folder cbtku ada dan sejajar dengan public_html
   2. Check permission: chmod 755 cbtku/
   3. Gunakan manual path input
   4. Verify path via cPanel File Manager

Q: "Permission denied" saat write .lic_hash?
A: chmod 755 /home/cbtsmpi/cbtku/app/Config/
   chmod 644 /home/cbtsmpi/cbtku/app/Config/.lic_hash

Q: "Database connection failed"?
A: 1. Check .env file di folder cbtku/
   2. Verify database credentials
   3. Test: mysql -u user -p database
   4. Checksum tidak akan di-generate (OK jika belum aktivasi)

Q: Script berhasil tapi masih error?
A: 1. Clear cache: rm -rf cbtku/writable/cache/*
   2. Clear browser cache
   3. Check error log lagi
   4. Mungkin ada error lain

Q: File "Controllers/Admin/License.php" not found?
A: Upload file dari localhost:
   app/Controllers/Admin/License.php
   Ke: cbtku/app/Controllers/Admin/License.php
