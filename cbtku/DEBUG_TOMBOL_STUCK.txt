================================================================================
DEBUG: Tombol Fullscreen Stuck
================================================================================

🔍 LANGKAH DEBUG
----------------

1. HARD REFRESH BROWSER
   ---------------------
   - Windows/Linux: Ctrl + F5
   - Mac: Cmd + Shift + R
   
   Ini penting untuk memastikan browser load file terbaru!

2. BUKA DEVELOPER TOOLS
   ---------------------
   - Tekan F12
   - Atau klik kanan → Inspect
   - Pilih tab "Console"

3. TEST BUTTON
   ------------
   a. Login siswa → Masuk ujian
   b. Overlay fullscreen muncul
   c. Klik tombol "MULAI UJIAN SEKARANG"
   d. LIHAT CONSOLE LOG

4. CHECK CONSOLE LOG
   ------------------
   Seharusnya muncul:
   
   ✅ [BUTTON] Button clicked, violationCount: 0, violationLimit: 4
   ✅ [BUTTON] Normal flow, proceeding to fullscreen
   ✅ Browser detection: { isSafari: false, isIOS: false }
   
   JIKA TIDAK MUNCUL:
   ❌ Button onclick tidak ter-trigger
   ❌ Kemungkinan: z-index overlay blocking button
   
   JIKA MUNCUL TAPI STUCK:
   ❌ Ada error di proceedToFullscreen()
   ❌ Check error message di console

5. CHECK BUTTON STATE
   -------------------
   Di Console, ketik:
   
   > const btn = document.getElementById('startFS')
   > console.log('disabled:', btn.disabled)
   > console.log('pointerEvents:', btn.style.pointerEvents)
   > console.log('opacity:', btn.style.opacity)
   > console.log('zIndex:', window.getComputedStyle(btn).zIndex)
   
   Expected:
   ✅ disabled: false
   ✅ pointerEvents: "" atau "auto"
   ✅ opacity: "" atau "1"
   ✅ zIndex: auto atau angka

6. CHECK OVERLAY STATE
   --------------------
   Di Console, ketik:
   
   > const overlay = document.getElementById('fsOverlay')
   > console.log('display:', overlay.style.display)
   > console.log('zIndex:', window.getComputedStyle(overlay).zIndex)
   > console.log('pointerEvents:', window.getComputedStyle(overlay).pointerEvents)
   
   Expected:
   ✅ display: "flex" atau ""
   ✅ zIndex: "9999" atau "9998"
   ✅ pointerEvents: "auto"
   
   JIKA z-index = "-1":
   ❌ Overlay di-hide tapi fullscreen gagal
   ❌ Button jadi tidak clickable

7. MANUAL TEST BUTTON
   -------------------
   Di Console, ketik:
   
   > document.getElementById('startFS').click()
   
   Atau:
   
   > document.getElementById('startFS').onclick()
   
   Apakah muncul log di console?
   - YES: Button event listener berfungsi
   - NO: Event listener tidak ter-attach

8. CHECK VIOLATION COUNT
   ----------------------
   Di Console, ketik:
   
   > console.log('violationCount:', violationCount)
   > console.log('violationLimit:', violationLimit)
   > console.log('ANTI_CHEAT:', ANTI_CHEAT)
   
   JIKA violationCount >= violationLimit:
   ❌ Button di-block karena violation
   ❌ Ini expected behavior (anti-cheat)

9. RESET OVERLAY Z-INDEX (JIKA STUCK)
   ------------------------------------
   Di Console, ketik:
   
   > const overlay = document.getElementById('fsOverlay')
   > overlay.style.zIndex = '9999'
   > overlay.style.pointerEvents = 'auto'
   > overlay.style.display = 'flex'
   
   Coba klik button lagi.

10. CHECK BROWSER COMPATIBILITY
    ----------------------------
    Di Console, ketik:
    
    > console.log(navigator.userAgent)
    
    Check browser version:
    - Chrome < 71: Tidak support (ada bug)
    - Chrome 71-90: Minor issues
    - Chrome 91+: Full support
    - Firefox: Full support
    - Safari: Partial support

📊 COMMON ISSUES
----------------

ISSUE 1: Button tidak respond sama sekali
------------------------------------------
Symptom: Klik button, tidak ada log di console
Cause: Event listener tidak ter-attach atau z-index blocking
Fix:
  > document.getElementById('startFS').onclick = function() { 
      console.log('Manual click'); 
      proceedToFullscreen(); 
    }

ISSUE 2: Button klik tapi stuck
--------------------------------
Symptom: Log muncul tapi fullscreen tidak aktif
Cause: Browser compatibility atau permission denied
Fix: Check browser version, update browser

ISSUE 3: Overlay z-index = -1
------------------------------
Symptom: Overlay tidak visible atau button tidak clickable
Cause: proceedToFullscreen() menurunkan z-index tapi fullscreen gagal
Fix:
  > document.getElementById('fsOverlay').style.zIndex = '9999'

ISSUE 4: Violation count exceeded
----------------------------------
Symptom: Button di-block dengan pesan error
Cause: Anti-cheat triggered (expected behavior)
Fix: Reset violation count atau disable anti-cheat untuk testing

ISSUE 5: Browser cache
-----------------------
Symptom: Perubahan kode tidak apply
Cause: Browser masih load file lama
Fix: Hard refresh (Ctrl+F5) atau clear cache
