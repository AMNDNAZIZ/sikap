✅ SELESAI - Tombol "MULAI UJIAN SEKARANG" sekarang selalu berfungsi

🔴 MASALAH SEBELUMNYA
---------------------
Ketika layar HP mati → Fullscreen exit → Overlay muncul → Tombol stuck → Harus refresh

🔍 ROOT CAUSE
-------------
1. Event listener hanya di-set sekali saat page load
2. Fullscreen change handler tidak reset button state
3. Tidak ada pageshow event listener untuk back navigation

✅ SOLUSI YANG DIIMPLEMENTASI
-----------------------------
1. Extract button setup ke function setupFullscreenButton() yang reusable
2. Call setupFullscreenButton() di 4 tempat:
   - Page load (initial setup)
   - Fullscreen exit (fullscreenChangeHandler)
   - Tab visible (visibilitychange handler)
   - Page show (pageshow event)
