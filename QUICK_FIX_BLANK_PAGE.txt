2️⃣ Pilih database aplikasi
3️⃣ Tab "Import"
4️⃣ Pilih file: update_database_manual.sql
5️⃣ Klik "Go"
6️⃣ Tunggu selesai
7️⃣ Import juga: update_migrations_table.sql
8️⃣ Akses aplikasi lagi → ✅ Normal

┌──────────────────────────────────────────────────────────────────────────────┐
│ SOLUSI B: LISENSI BELUM DIAKTIVASI (15% KASUS)                              │
└──────────────────────────────────────────────────────────────────────────────┘

GEJALA:
❌ Tidak ada data lisensi
🔄 Redirect ke /activate (NORMAL!)

SOLUSI:
1️⃣ Akses: http://yourdomain.com/activate

3️⃣ Klik "Aktivasi"
4️⃣ ✅ Aplikasi normal

NOTE: Redirect ke /activate adalah NORMAL jika belum ada lisensi!

SOLUSI:

3️⃣ Sistem auto-sync dengan server

└─ 4. ✅ Aplikasi normal

JIKA LISENSI EXPIRED:

║ TROUBLESHOOTING                                                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

   → Import update_database_manual.sql

   → Import update_database_manual.sql (update struktur)

   → Check diagnostic: diagnostic_blank_page.php
   → Aktivasi ulang jika perlu

❓ Blank page tanpa error
   → Check log: writable/logs/log-YYYY-MM-DD.log
   → Enable error display di index.php (temporary)
