║      QUICK FIX: Jeda Lama Saat Submit Ujian CBT            ║
╚══════════════════════════════════════════════════════════════╝

MASALAH:
❌ Jeda lama (3-6 detik) setelah klik konfirmasi
❌ Tidak ada feedback visual
❌ Terkesan hang atau lambat

ROOT CAUSE:
🔴 Tidak ada loading indicator
🔴 Proses server memakan waktu (scoring, validation)
🔴 User tidak tahu proses sedang berjalan

SOLUSI:
✅ Tambah loading indicator (SweetAlert2)
✅ Update message untuk retry (jika 403)
✅ Success message before redirect

FILES MODIFIED:
📝 app/Views/siswa/cbt/ujian.php
   - Tambah loading indicator di submitExam()
   - Tambah success message
