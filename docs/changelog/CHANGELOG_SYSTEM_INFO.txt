================================================================================
SISTEM CHANGELOG OTOMATIS
================================================================================

MASALAH SEBELUMNYA:
-------------------
❌ Changelog di production tidak terupdate saat update file
❌ Harus manual update file changelogs_sync.php
❌ Sering lupa update, changelog tidak sinkron

SOLUSI SEKARANG:
----------------
✅ Otomatis sync changelog saat generate patch ZIP
✅ Otomatis sync changelog saat jalankan migrasi
✅ Tidak perlu manual update file
✅ Changelog selalu konsisten antara dev & production

================================================================================
CARA KERJA SISTEM
================================================================================

DEVELOPMENT (Localhost):
------------------------
1. Developer tambah changelog di database
2. Developer klik "Download Zip" di halaman Updater
3. Sistem OTOMATIS:
   - Sync changelog dari database ke file changelogs_sync.php
   - Update LAST_UPDATE di Constants.php
   - Generate ZIP dengan semua file terbaru

PRODUCTION (Hosting):
---------------------
1. Admin upload ZIP ke production
2. Admin klik "Update File" (extract ZIP)
3. Admin klik "Jalankan Migrasi"
4. Sistem OTOMATIS:
   - Jalankan migrasi database
   - Sync changelog dari file ke database
   - Update tabel changelogs

================================================================================
FILE YANG TERLIBAT
================================================================================

1. app/Database/changelogs_sync.php
   - File sync changelog (auto-generated)
   - Berisi array changelog dari database
   - Di-include di patch ZIP

2. app/Controllers/Admin/Updater.php
   - Method: syncChangelogsToFile() - sync DB ke file
   - Method: syncChangelogsFromData() - sync file ke DB
   - Method: generatePatch() - otomatis call syncChangelogsToFile()
   - Method: runMigrations() - otomatis call syncChangelogsFromData()

3. app/Database/sync_changelogs_to_file.php
   - Script helper untuk manual sync (jika diperlukan)
   - Bisa dijalankan via CLI atau browser

================================================================================
TROUBLESHOOTING
================================================================================

MASALAH: Changelog tidak muncul di production
SOLUSI:
1. Cek: SELECT * FROM changelogs;
2. Jika kosong, jalankan ulang "Jalankan Migrasi"
3. Atau tambah manual via SQL

MASALAH: File changelogs_sync.php tidak terupdate
SOLUSI:
1. Jalankan: php app/Database/sync_changelogs_to_file.php
2. Generate ulang patch ZIP

MASALAH: Error saat sync
SOLUSI:
1. Cek error log: writable/logs/
2. Cek permission file: app/Database/changelogs_sync.php
3. Cek koneksi database
