║         QUICK FIX: CBT 403 Forbidden & Loading Lama         ║
╚══════════════════════════════════════════════════════════════╝

MASALAH:
1. Jeda lama antara klik mulai dengan notifikasi fullscreen
2. Error 403 Forbidden saat save answer di ujian panjang

ROOT CAUSE:
- CSRF token expired setelah 2 jam (7200 detik)
- Ujian > 2 jam = semua save request gagal 403
- Loading indicator tidak jelas saat mulai ujian

SOLUSI YANG SUDAH DITERAPKAN:
✅ Perpanjang CSRF expires dari 2 jam → 6 jam (21600 detik)
✅ Implement auto-refresh CSRF token setiap 60 menit
✅ Auto-retry save jika 403 error (token expired)
✅ Loading indicator saat mulai ujian
✅ Endpoint refreshCsrf untuk regenerate token

FILES MODIFIED:
1. app/Config/Security.php
   - expires: 7200 → 21600 (6 hours)

2. app/Controllers/Siswa/Cbt.php
   - Added refreshCsrf() method

3. app/Views/siswa/cbt/ujian.php

   - Added auto-retry on 403 error
   - Added loading spinner & feedback
   - Improved error handling
