========================================
INSTRUKSI CEK SUB DIMENSI TIDAK MUNCUL
========================================

LANGKAH 1: CEK BROWSER CONSOLE
-------------------------------
1. Buka halaman penilaian detail
2. Tekan F12 → Tab Console
3. Lihat output, cari baris:
   - "Rubrik data loaded:"
   - "Has sub_dimensi: true/false"

4. Klik tanda ▶ untuk expand array
5. Lihat apakah ada field "sub_dimensi" dengan nilai

JIKA sub_dimensi: null → Lanjut ke Langkah 2


LANGKAH 2: CEK DATABASE
-----------------------
Jalankan query ini di phpMyAdmin atau MySQL client:

SELECT id, document_id, dimensi_profil, sub_dimensi 
FROM kokurikuler_rubrik 
WHERE document_id = 12;

(Ganti 12 dengan ID dokumen Anda)

JIKA kolom sub_dimensi kosong/NULL → Lanjut ke Langkah 3


LANGKAH 3: HAPUS DAN REGENERATE
--------------------------------
Jalankan query ini:

DELETE FROM kokurikuler_rubrik WHERE document_id = 12;

Kemudian buka browser:
http://localhost:8080/siakad/admin/kokurikuler/view/12

Rubrik akan otomatis di-generate ulang dengan sub_dimensi.


LANGKAH 4: TEST LAGI
---------------------
1. Refresh halaman penilaian detail
2. Pilih Dimensi dari dropdown
3. Sub Dimensi seharusnya sudah muncul


JIKA MASIH BELUM MUNCUL:
-------------------------
Kirimkan screenshot dari:
1. Browser Console (F12 → Console)
2. Network Tab (F12 → Network → request "get-rubrik")
3. Hasil query database di Langkah 2
