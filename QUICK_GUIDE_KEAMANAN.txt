CARA IMPLEMENTASI (15-30 MENIT)
================================================================================

Step 1: BACKUP (WAJIB!)
-----------------------
mysqldump -u root -p siakad > backup.sql
cp -r app app_backup

Step 2: JALANKAN MIGRASI
-----------------------
cd C:\xampp\htdocs\siakad
php spark migrate

Output: "Migrated: 2026-02-25-000001_AddHardwareSignatureToLicense"

Step 3: VERIFIKASI
-----------------------
# Cek kolom baru ditambahkan
SELECT * FROM app_license;

# Cek security hash ter-generate
ls app/Config/.security_hash

Step 4: TEST APLIKASI
-----------------------
1. Akses: http://localhost/siakad
2. Login sebagai admin
3. Navigasi beberapa halaman
4. Pastikan tidak ada error
