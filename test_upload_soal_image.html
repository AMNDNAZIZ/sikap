Troubleshooting

Jika Upload Gagal:

  1. Check Console (F12): Lihat error di browser console
  2. Check Network Tab: Lihat response dari server
  3. Check Permissions: 
    chmod 775 public/uploads/soal_images
  4. Check Error Log: 
    tail -f writable/logs/log-*.log
  5. Check Apache Error Log: 
    tail -f /var/log/apache2/error.log

Common Issues:

  • 403 Forbidden: Check .htaccess di public/uploads/
  • 404 Not Found: Check route uploadImage exists
  • 500 Server Error: Check PHP error log
  • CSRF Error: Login dulu sebagai admin
  • Permission Denied: Check folder writable

Expected Response:

{
  "location": "http://localhost/siakad/uploads/soal_images/1234567890_abc.jpg",
  "url": "http://localhost/siakad/uploads/soal_images/1234567890_abc.jpg"
}
